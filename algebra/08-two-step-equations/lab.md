# Lab 8: Two-Step Equations

## Main idea

For ax + b = c, undo addition first, then undo multiplication.

## Learning goal

Solve a two-step equation and check it.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. In this folder, run:

```bash
node app.js 3 4 19
```

The values after `app.js` are inputs. Change them and run the command again. The simulation needs no packages or setup.

## Directions

1. Follow each undo step.
2. Try `node app.js 2 5 15`.
3. Create an equation whose answer is 4.

## Think about it

- What pattern did the simulation show?
- What changed when you changed an input, and why?
- Explain the main idea in one simple sentence.

## Success check

You are ready to move on when you can predict an output, test it, and explain whether your prediction was correct.
