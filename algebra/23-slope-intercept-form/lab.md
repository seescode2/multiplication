# Lab 23: Slope-Intercept Form

## Main idea

In y = mx + b, m is the slope and b is where the line crosses the y-axis.

## Learning goal

Generate points on a line from m and b.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. In this folder, run:

```bash
node app.js 2 1
```

The values after `app.js` are inputs. Change them and run the command again. The simulation needs no packages or setup.

## Directions

1. Run y = 2x + 1.
2. Change b and watch the y-value at x = 0.
3. Change m and compare how quickly y changes.

## Think about it

- What pattern did the simulation show?
- What changed when you changed an input, and why?
- Explain the main idea in one simple sentence.
