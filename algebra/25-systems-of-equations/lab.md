# Lab 25: Systems of Equations

## Main idea

A solution to two equations is a point that makes both equations true. On a graph, it is where the lines meet.

## Learning goal

Find the intersection of two lines.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. In this folder, run:

```bash
node app.js 2 1 -1 7
```

The values after `app.js` are inputs. Change them and run the command again. The simulation needs no packages or setup.

## Directions

1. Run y = 2x + 1 and y = -x + 7.
2. Substitute the answer into both rules.
3. Try lines with equal slopes.
