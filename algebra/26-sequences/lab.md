# Lab 26: Arithmetic Sequences

## Main idea

An arithmetic sequence adds the same amount each time. That amount is the common difference.

## Learning goal

Generate terms using a first term and common difference.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. In this folder, run:

```bash
node app.js 4 3 8
```

The values after `app.js` are inputs. Change them and run the command again. The simulation needs no packages or setup.

## Directions

1. Start at 4 and add 3.
2. Try a negative common difference.
3. Predict the eighth term before running.

## Think about it

- What pattern did the simulation show?
- What changed when you changed an input, and why?
- Explain the main idea in one simple sentence.
