# Lab 28: Factoring Common Factors

## Main idea

Factoring rewrites a sum as a product. A greatest common factor can be pulled out of every term.

## Learning goal

Factor ax + b using the greatest common factor.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. In this folder, run:

```bash
node app.js 12 18
```

The values after `app.js` are inputs. Change them and run the command again. The simulation needs no packages or setup.

## Directions

1. Factor 12x + 18.
2. Multiply the result back out to check.
3. Try two numbers with no common factor except 1.

## Think about it

- What pattern did the simulation show?
- What changed when you changed an input, and why?
- Explain the main idea in one simple sentence.
