# Lab 30: Quadratic Formula

## Main idea

The quadratic formula solves ax² + bx + c = 0 using its coefficients.

## Learning goal

Find real roots and check the discriminant.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. In this folder, run:

```bash
node app.js 1 -5 6
```

The values after `app.js` are inputs. Change them and run the command again. The simulation needs no packages or setup.

## Directions

1. Solve x² - 5x + 6 = 0.
2. Try `node app.js 1 2 1` for one repeated root.
3. Try a case with no real roots.

## Think about it

- What pattern did the simulation show?
- What changed when you changed an input, and why?
- Explain the main idea in one simple sentence.
