# Algebra Simulation Labs

Thirty small, beginner-friendly algebra labs. Each folder contains a `lab.md` lesson and a dependency-free Node.js `app.js` simulation. The lessons start with variables and build toward functions, systems, polynomials, and quadratics.

## How to use the labs

1. Choose a concept below and open its `lab.md`.
2. Read the main idea and learning goal.
3. Run the example command from inside that concept folder.
4. Change the inputs, predict the result, and run it again.
5. Answer the reflection questions before moving on.
