# Lab 3: Continuity

## Main idea

A function is continuous when its graph has no break at the point: the limit and actual value agree.

## Learning goals

By the end of this lab, you should be able to:

1. Explain **continuity** in your own words.
2. Identify the input, calculation, and output in the simulation.
3. Predict how a small input change will affect the result.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 2 4
```

The numbers after `app.js` are inputs. The program uses safe defaults if you leave them out, and it needs no packages.

## Directions

1. Read the main idea, then write down what you expect the example command to show.
2. Run `node app.js 2 4` and label the important input and output.
3. Run `node app.js 2 5` to make the point value disagree with the nearby values.
4. Open `app.js`. Find the line that performs the main calculation and describe it without code words.
5. Run your changed example and compare it with your prediction.

## Think about it

- What stayed the same when the inputs changed?
- What changed, and why?
- How does the output demonstrate the main idea?
- Where might this kind of change or accumulation appear in real life?

## Mini challenge

Choose one new valid input, write a prediction, and test it. If the result surprises you, use the intermediate output to explain the difference.

## Success check

You are ready to move on when you can explain the main idea simply, run the simulation, and correctly predict one changed result.
