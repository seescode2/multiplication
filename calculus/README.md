# Calculus Simulation Labs

Thirty small, beginner-friendly calculus labs. Each folder contains a guided `lab.md` and a dependency-free Node.js `app.js` simulation. The sequence starts with limits, develops derivatives and integrals, and ends with differential equations and improper integrals.

## How to use the labs

1. Start with a concept below and open its `lab.md`.
2. Read the main idea and make the requested prediction.
3. Run the example from inside that concept folder (for example, `cd 01-limits-by-table && node app.js 2`).
4. Change the inputs, run the simulation again, and explain what changed.
5. Answer the reflection questions before continuing.

All simulations require only Node.js. They do not install packages, access the network, or write files.
