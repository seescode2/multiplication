# Lab: Recursion and recurrences

## What you are learning

A recurrence defines a value using smaller earlier values. Fibonacci adds the previous two values.

By the end of this lab, you should be able to explain **recursion and recurrences** in your own words and point to the part of the output that demonstrates it.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this lesson folder, run:

```bash
node simulation.js 10
```

The program uses built-in JavaScript only; no package installation is needed.

## Directions

1. Predict the output before running the command. Write down your guess.
2. Run the simulation and compare the result with your prediction.
3. Read `simulation.js`. Find the line or loop that represents the main idea.
4. Change one input on the command line (or one sample value in the file), then run it again.
5. Explain why the output changed using the concept, not just the code.

## Check your understanding

- What are the objects or values in this simulation?
- What rule does the simulation apply to them?
- Which output is evidence that the rule worked?
- Can you invent a tiny example and solve it by hand?

## Small challenge

Modify the simulation to print one extra useful fact. Keep the example small enough that you can check the answer yourself.
