# Discrete Math: 30 Tiny Labs

Each numbered folder introduces one discrete-math idea in simple language. Every lab has:

- `lab.md` with a learning goal, directions, questions, and a challenge
- `simulation.js` with a small Node.js simulation using no external packages

## How to use the labs

Start at lesson 1 or choose any topic. Open its `lab.md`, make a prediction, and run the listed command from that lesson folder. For example:

```bash
cd 01-sets
node simulation.js apple banana apple pear
```

Node.js 18 or newer is recommended. Random simulations may give different results on each run.
