# Lab: Angle Basics

## Main idea

An angle is made by two rays sharing one endpoint, called the vertex. We measure its turn in degrees.

## Learning goal

Classify an angle by its degree measure.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 65
```

The numbers after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run with 65°.
2. Test 90°, 120°, and 180°.
3. Write a rule for acute angles.
