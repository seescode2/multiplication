# Lab: Complementary Angles

## Main idea

Two angles are complementary when they add to 90°, like pieces that fill a right angle.

## Learning goal

Find the missing complement.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 35
```

The numbers after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run the example.
2. Try 10° and 45°.
3. What happens to the complement when the first angle grows?


## Think about it
