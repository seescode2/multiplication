# Lab: Triangle Types by Angles

## Main idea

A triangle can be acute, right, or obtuse based on its largest angle. Its angles always total 180°.

## Learning goal

Classify a triangle from three angles.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 30 60 90
```

The numbers after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run the 30-60-90 triangle.
2. Try 60, 60, 60.
3. Try 20, 40, 120 and identify the largest angle.


## Think about it

You are ready to move on when you can predict one output before running the simulation and explain whether your prediction was correct.
