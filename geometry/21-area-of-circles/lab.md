# Lab: Area of Circles

## Main idea

A circle’s area is π times radius squared: A = πr². Squaring means radius times itself.

## Learning goal

Calculate and compare circle areas.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 3
```

The numbers after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run with radius 3.
2. Try radius 6. Did area merely double?
3. Find the area using π ≈ 3.14 by hand.
