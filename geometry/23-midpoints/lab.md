# Lab: Midpoints

## Main idea

A midpoint sits exactly halfway between two endpoints. Average the x-values and average the y-values.

## Learning goal

Calculate the midpoint of two points.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 2 1 8 5
```

The numbers after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run the example.
2. Reverse the endpoints.
3. Choose endpoints whose midpoint is (0, 0).
