Try it yourself

  1. Start at P = (3, 2), C = (0, 0). Predict P′ when k = 2, then check the graph.
  2. Choose ½×. Compare the coordinates and distance from the center.
  3. Choose Triangle PQR. Compare side lengths and area at 2× and ½×.
  4. Try 1×, 0, and −1×. Which leaves every point unchanged? Which moves points across the center?
  5. Move C to (1, 1). Does multiplying the original coordinates still work?

A dilation uses P′ = C + k(P − C). Distances scale by |k|; areas scale by k². For nonzero k, angles stay the same.
