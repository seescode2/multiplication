# Lab 1: Matrix Basics

## Big idea

A matrix is a rectangular table of numbers. Rows go across and columns go down.

## Learning goal

By the end, you should be able to explain **matrix basics** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 01-matrix-basics/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `01-matrix-basics/app.js` and match each input number to the output it helps create.

## Experiment

Change one entry and the number of rows. Predict the reported size and selected entry before running.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. How do the two array indexes relate to a matrix row and column?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
