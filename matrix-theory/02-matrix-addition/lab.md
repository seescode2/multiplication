# Lab 2: Matrix Addition

## Big idea

Add two matrices by adding numbers in matching positions.

## Learning goal

By the end, you should be able to explain **matrix addition** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 02-matrix-addition/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `02-matrix-addition/app.js` and match each input number to the output it helps create.

## Experiment

Change B[0][1] to 10. Predict which entry of the sum changes.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. Why must matrices have the same shape to be added?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
