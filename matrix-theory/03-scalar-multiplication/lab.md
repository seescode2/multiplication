# Lab 3: Scalar Multiplication

## Big idea

A scalar is one number. Multiplying by it stretches every entry equally.

## Learning goal

By the end, you should be able to explain **scalar multiplication** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 03-scalar-multiplication/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `03-scalar-multiplication/app.js` and match each input number to the output it helps create.

## Experiment

Add 0 and 3 to the list of scalars, then compare their effects.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. What does a negative scalar do to every sign?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
