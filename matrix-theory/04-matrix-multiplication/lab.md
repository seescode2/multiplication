# Lab 4: Matrix Multiplication

## Big idea

Matrix multiplication combines each row of the first matrix with each column of the second.

## Learning goal

By the end, you should be able to explain **matrix multiplication** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 04-matrix-multiplication/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `04-matrix-multiplication/app.js` and match each input number to the output it helps create.

## Experiment

Change B’s first column and hand-calculate the first result entry.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. Why must A’s column count equal B’s row count?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
