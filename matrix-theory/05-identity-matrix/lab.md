# Lab 5: Identity Matrix

## Big idea

The identity matrix acts like the number 1: multiplying by it leaves a matrix unchanged.

## Learning goal

By the end, you should be able to explain **identity matrix** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 05-identity-matrix/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `05-identity-matrix/app.js` and match each input number to the output it helps create.

## Experiment

Change A’s entries, rerun, and check whether A × I still equals A.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. Where are the 1s and 0s placed in an identity matrix?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
