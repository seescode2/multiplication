# Lab 6: Zero Matrix

## Big idea

A zero matrix contains only zeros. Adding it changes nothing; multiplying by it gives zeros.

## Learning goal

By the end, you should be able to explain **zero matrix** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 06-zero-matrix/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `06-zero-matrix/app.js` and match each input number to the output it helps create.

## Experiment

Replace A with another 2×2 matrix and test both rules again.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. How is the zero matrix like the ordinary number 0?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
