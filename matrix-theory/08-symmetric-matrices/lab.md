# Lab 8: Symmetric Matrices

## Big idea

A symmetric matrix looks the same after it is transposed.

## Learning goal

By the end, you should be able to explain **symmetric matrices** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 08-symmetric-matrices/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `08-symmetric-matrices/app.js` and match each input number to the output it helps create.

## Experiment

Change just A[0][1]. Then change its mirror A[1][0] to match.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. Which entries must come in matching pairs?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
