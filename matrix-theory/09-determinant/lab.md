# Lab 9: Determinant

## Big idea

The determinant is one number that tells how a square matrix scales area. Zero means the transformation flattens space.

## Learning goal

By the end, you should be able to explain **determinant** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 09-determinant/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `09-determinant/app.js` and match each input number to the output it helps create.

## Experiment

Edit the first diagonal matrix to use 4 and 5. Predict its area scale.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. What geometric warning does determinant 0 give?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
