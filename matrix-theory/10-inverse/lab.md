# Lab 10: Inverse Matrix

## Big idea

An inverse undoes a matrix transformation, just as dividing can undo multiplying.

## Learning goal

By the end, you should be able to explain **inverse matrix** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 10-inverse/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `10-inverse/app.js` and match each input number to the output it helps create.

## Experiment

Try A = [[1,2],[2,4]]. Read the error and connect it to the determinant.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. How can the identity matrix show that an inverse worked?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
