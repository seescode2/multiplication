# Lab 11: Linear Transformations

## Big idea

A matrix can move vectors while keeping straight lines straight and the origin fixed.

## Learning goal

By the end, you should be able to explain **linear transformations** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 11-linear-transformations/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `11-linear-transformations/app.js` and match each input number to the output it helps create.

## Experiment

Change A[0][1] from 1 to 2 and watch the square shear farther.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. Which point never moves in a linear transformation?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
