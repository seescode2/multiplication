# Lab 14: Shear Matrix

## Big idea

A shear slides one layer of space farther than another, slanting shapes.

## Learning goal

By the end, you should be able to explain **shear matrix** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 14-shear-matrix/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `14-shear-matrix/app.js` and match each input number to the output it helps create.

## Experiment

Try shear amounts -1 and 2 and sketch the resulting corners.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. Which coordinate remains unchanged in this horizontal shear?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
