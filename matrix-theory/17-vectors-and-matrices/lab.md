# Lab 17: Vectors and Matrices

## Big idea

A matrix times a vector makes each output from a weighted mix of the inputs.

## Learning goal

By the end, you should be able to explain **vectors and matrices** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 17-vectors-and-matrices/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `17-vectors-and-matrices/app.js` and match each input number to the output it helps create.

## Experiment

Change v one coordinate at a time and notice which outputs respond.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. How does one row of A create one output number?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
