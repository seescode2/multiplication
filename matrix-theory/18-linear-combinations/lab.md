# Lab 18: Linear Combinations

## Big idea

A matrix-vector product is a weighted sum of the matrix’s columns.

## Learning goal

By the end, you should be able to explain **linear combinations** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 18-linear-combinations/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `18-linear-combinations/app.js` and match each input number to the output it helps create.

## Experiment

Try weights [0,1], [1,0], and [1,1].

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. What result do the weights [1,0] select?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
