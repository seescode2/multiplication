# Lab 19: Span

## Big idea

The span is every vector reachable by mixing given vectors with any scalar weights.

## Learning goal

By the end, you should be able to explain **span** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 19-span/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `19-span/app.js` and match each input number to the output it helps create.

## Experiment

Replace b with [2,0]. Do the printed points still spread over a plane?

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. How does using parallel vectors limit their span?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
