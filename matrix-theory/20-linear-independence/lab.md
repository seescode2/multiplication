# Lab 20: Linear Independence

## Big idea

Vectors are independent when none can be built from the others.

## Learning goal

By the end, you should be able to explain **linear independence** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 20-linear-independence/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `20-linear-independence/app.js` and match each input number to the output it helps create.

## Experiment

Create one parallel pair and one non-parallel pair of your own.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. Why does a nonzero determinant signal independence in 2D?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
