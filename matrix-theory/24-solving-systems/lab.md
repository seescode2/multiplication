# Lab 24: Solving Linear Systems

## Big idea

The equation Ax=b packages several linear equations into one matrix equation.

## Learning goal

By the end, you should be able to explain **solving linear systems** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 24-solving-systems/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `24-solving-systems/app.js` and match each input number to the output it helps create.

## Experiment

Change b to [3,0], solve again, and check the answer.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. What does multiplying by A inverse do to both sides?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
