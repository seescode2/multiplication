# Lab 25: Row Operations

## Big idea

Row operations rewrite equations without changing their solutions.

## Learning goal

By the end, you should be able to explain **row operations** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 25-row-operations/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `25-row-operations/app.js` and match each input number to the output it helps create.

## Experiment

Change the right-hand side values 5 and 11, then follow the same row steps.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. Where is the final solution visible in the reduced matrix?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
