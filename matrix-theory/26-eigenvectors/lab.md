# Lab 26: Eigenvectors

## Big idea

An eigenvector keeps its direction when transformed; it is only scaled.

## Learning goal

By the end, you should be able to explain **eigenvectors** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 26-eigenvectors/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `26-eigenvectors/app.js` and match each input number to the output it helps create.

## Experiment

Try vectors [2,0], [0,-3], and [2,2].

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. Which coordinate-axis directions are eigenvectors here?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
