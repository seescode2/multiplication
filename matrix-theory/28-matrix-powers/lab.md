# Lab 28: Matrix Powers

## Big idea

A matrix power repeats the same transformation many times.

## Learning goal

By the end, you should be able to explain **matrix powers** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 28-matrix-powers/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `28-matrix-powers/app.js` and match each input number to the output it helps create.

## Experiment

Run through power 10 and describe the pattern in the first coordinate.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. Why is A to the zeroth power the identity matrix?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
