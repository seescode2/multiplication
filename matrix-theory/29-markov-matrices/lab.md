# Lab 29: Markov Matrices

## Big idea

A Markov matrix moves probabilities between states while their total stays 1.

## Learning goal

By the end, you should be able to explain **markov matrices** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 29-markov-matrices/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `29-markov-matrices/app.js` and match each input number to the output it helps create.

## Experiment

Start from [0,1], then compare the long-run probabilities.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. Why must each column of this matrix add to 1?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
