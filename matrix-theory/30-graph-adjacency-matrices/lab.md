# Lab 30: Graph Adjacency Matrices

## Big idea

An adjacency matrix records graph connections. Its powers count walks between nodes.

## Learning goal

By the end, you should be able to explain **graph adjacency matrices** in your own words and connect the printed numbers to the big idea above.

## Run the simulation

1. Open a terminal in the `matrix-theory` folder.
2. Run `node 30-graph-adjacency-matrices/app.js`.
3. Read the output from top to bottom. Do not worry if you cannot predict it yet.
4. Open `30-graph-adjacency-matrices/app.js` and match each input number to the output it helps create.

## Experiment

Remove the connection between nodes 1 and 3 in both mirrored entries, then rerun.

Run the program again after each edit. Restore the file when you finish if you want the original example back.

## Check your understanding

1. Why are both A[0][2] and A[2][0] changed for an undirected graph?
2. What pattern stayed the same when you changed the numbers?
3. Explain the result to someone without using the word “matrix.”

## Success check

You are ready to move on when you can predict at least one line of output before running the simulation and explain why it appears.
