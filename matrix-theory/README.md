# Matrix Theory: 30 Tiny Labs

This collection introduces matrix ideas one small step at a time. Each numbered folder contains:

- `lab.md`: a plain-language goal, directions, an experiment, and reflection questions.
- `app.js`: a runnable simulation that prints its results in the terminal.

## Requirements

Install [Node.js](https://nodejs.org/) 18 or newer. No packages need to be installed.

## Run a lab

From this directory:

```bash
node run.js 1
node run.js 12
node 12-rotation-matrix/app.js
```

List all labs with `node run.js --list`. Check every simulation with `npm test`. Work in order if matrices are new to you; later labs reuse earlier ideas.
