# Lab: Friction

## Main idea

Friction is a force that resists sliding. Rougher contact usually creates more friction.

## Learning goal

Compare friction on surfaces with different friction values.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 10 0.2 0.7
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Compare the same 10-newton normal force on two surfaces.
2. Choose which surface is harder to slide across.
3. Double the normal force and observe both friction forces.
