# Lab: Momentum

## Main idea

Momentum describes motion using both mass and velocity. Momentum = mass × velocity.

## Learning goal

Compare the momentum of moving objects.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 2 6 4 3
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Compare a 2-kg object at 6 m/s with a 4-kg object at 3 m/s.
2. Find two new mass-and-velocity pairs with equal momentum.
3. Make one velocity negative and explain the sign.
