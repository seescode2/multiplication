# Lab: Kinetic Energy

## Main idea

Kinetic energy is energy of motion. Faster objects have much more kinetic energy because speed is squared.

## Learning goal

See how mass and speed affect kinetic energy.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 2 3
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Find the energy of a 2-kg object moving at 3 m/s.
2. Double the mass and compare.
3. Reset the mass, double the speed, and look for a four-times change.
