# Lab: Density and Buoyancy

## Main idea

Density is mass packed into volume. An object less dense than water tends to float; one more dense tends to sink.

## Learning goal

Predict floating or sinking from mass and volume.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 500 750
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Test a 500-gram object with a volume of 750 cubic centimeters.
2. Keep volume fixed and increase mass until it sinks.
3. Make density exactly 1 g/cm³ and see the result.
