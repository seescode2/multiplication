# Lab: Temperature and Particle Motion

## Main idea

Temperature is connected to the average motion of particles. Hotter particles move faster on average.

## Learning goal

Watch a simple particle display change with temperature.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 20 80
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Compare the 20°C and 80°C particle displays.
2. Notice that the model shows a trend, not exact particle paths.
3. Try two equal temperatures and compare.
