# Lab: Wave Basics

## Main idea

A wave carries energy through repeated disturbances. Amplitude is wave height, and wavelength is the distance between matching points.

## Learning goal

Build a simple wave and change its amplitude and wavelength.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 3 8
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run with amplitude 3 and wavelength 8.
2. Double the amplitude and inspect the taller pattern.
3. Try wavelength 4 and count how often the pattern repeats.

## Think about it

- What did you predict before each run?
- What changed when you changed one input?
- Where might you notice this concept outside the lab?
- Explain the main idea in your own words.

## Success check

You are ready to move on when you can predict one result, test it, and use the output to explain the concept.
