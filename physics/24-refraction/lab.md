# Lab: Refraction

## Main idea

Light changes direction when it enters a material where it travels at a different speed. This bending is refraction.

## Learning goal

See how light bends when moving from air into glass.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 40 1.5
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Send light into glass at 40° from the normal.
2. Increase the refractive index and observe the refracted angle.
3. Try an incoming angle of 0°. Does the ray bend?
