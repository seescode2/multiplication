# Lab: Voltage, Current, and Resistance

## Main idea

Voltage pushes charge, current is the flow of charge, and resistance makes that flow harder. Ohm's law says current = voltage ÷ resistance.

## Learning goal

Build a one-resistor circuit using Ohm's law.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 9 3
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Use a 9-volt battery and a 3-ohm resistor.
2. Double resistance while keeping voltage fixed.
3. Double voltage while keeping resistance fixed.

## Think about it

- What did you predict before each run?
- What changed when you changed one input?
- Where might you notice this concept outside the lab?
- Explain the main idea in your own words.

## Success check
