# Lab: Electromagnets

## Main idea

Electric current in a coil creates a magnetic field. More current or more coil turns makes a stronger electromagnet in this simple model.

## Learning goal

Change current and coil turns to compare field strength.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 2 20
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run with 2 amperes and 20 turns.
2. Double just the current, then just the turns.
3. Reverse the current with -2 and observe the pole direction.
