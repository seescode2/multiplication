# Lab: Radioactive Decay and Half-Life

## Main idea

A half-life is the time for about half of a large group of unstable atoms to decay.

## Learning goal

Follow an ideal amount through several half-lives.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 1000 5
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Start with 1,000 atoms and follow five half-lives.
2. Predict the amount after three half-lives.
3. Double the starting amount and compare the fraction remaining.

## Think about it
