# Physics Simulation Labs

Thirty small, beginner-friendly physics labs. Each folder contains a `lab.md` lesson and a dependency-free Node.js `app.js` simulation.

## How to use the labs

1. Choose a concept below.
2. Open its `lab.md` and read the main idea and learning goal.
3. Predict what will happen, then run the shown command from that concept's folder.
4. Change one input at a time, run the simulation again, and explain what changed.

These are simplified teaching models. Each lab says when it leaves out real-world effects or uses a rough visual comparison.
