# Lab: Trigonometric Identities

## Big idea

An identity is an equation true for every allowed angle. The Pythagorean identity says sin²x + cos²x = 1.

## Learning goals

By the end of this lab, you should be able to:

1. Explain **trigonometric identities** in your own words.
2. Identify the inputs, rule, and outputs in the simulation.
3. Predict one output before running the code.
4. Change a value and explain why the output changes.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node simulation.js
```

## Directions

1. Open `simulation.js` and read it from top to bottom. It is okay if some syntax is new.
2. Run it once without making changes. Write down one pattern you notice.
3. Add angles and check how close the computer result is to 1.
4. Before running it again, predict one result. Then run it and check your prediction.
5. Restore any values that caused an error before moving on.

## Think about it

- What stayed the same in every run?
- What changed, and which edit caused that change?
- How does the output demonstrate this lab's big idea?
- Describe the concept to a friend without using a formula.

## Mini challenge

Make one safe change that produces a noticeably different result. Add a comment beginning with
`// My prediction:` to the program, run it, and compare the result with your prediction.

## Check your understanding

You are ready to continue when you can state the big idea, point to the important value or rule in
`simulation.js`, and correctly predict what one small edit will do.
