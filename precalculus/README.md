# Precalculus: 30 Small Labs

These labs introduce precalculus one small idea at a time. Each folder contains:

- `lab.md`: a plain-language lesson, learning goals, directions, questions, and a challenge.
- `simulation.js`: a tiny Node.js program that makes the main idea visible with numbers.

Start with Lab 1 and work in order, or choose a topic. In any lab folder, run
`node simulation.js`. Predict first, experiment second, and explain what happened in your own words.
