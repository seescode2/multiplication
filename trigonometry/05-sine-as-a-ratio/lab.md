# Lab: Sine as a Ratio

## Main idea

In a right triangle, sine compares the side opposite an angle with the hypotenuse: sin(angle) = opposite ÷ hypotenuse.

## Learning goal

Calculate sine from two side lengths.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 3 5
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run with opposite 3 and hypotenuse 5.
2. Double both sides. Does sine change?
3. Try opposite 5 and hypotenuse 5.
