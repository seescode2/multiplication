# Lab: Cosine as a Ratio

## Main idea

In a right triangle, cosine compares the side beside an angle with the hypotenuse: cos(angle) = adjacent ÷ hypotenuse.

## Learning goal

Calculate cosine from two side lengths.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 4 5
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run with adjacent 4 and hypotenuse 5.
2. Double both sides. Does cosine change?
3. Try adjacent 0 and hypotenuse 5.
