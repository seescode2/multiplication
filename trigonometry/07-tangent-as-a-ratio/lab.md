# Lab: Tangent as a Ratio

## Main idea

In a right triangle, tangent compares the opposite and adjacent sides: tan(angle) = opposite ÷ adjacent.

## Learning goal

Calculate tangent from two leg lengths.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 3 4
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run with opposite 3 and adjacent 4.
2. Double both sides.
3. Make the opposite side larger than the adjacent side.

## Think about it

- What stayed the same?
