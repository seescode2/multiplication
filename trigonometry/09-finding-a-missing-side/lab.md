# Lab: Finding a Missing Side

## Main idea

A trig ratio can connect a known angle and side to an unknown side. For example, opposite = hypotenuse × sin(angle).

## Learning goal

Find an opposite side using sine.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 30 10
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run with 30° and hypotenuse 10.
2. Keep the angle and double the hypotenuse.
3. Try an angle of 90°.
