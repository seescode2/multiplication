# Lab: Inverse Sine

## Main idea

Inverse sine works backward: it finds an angle when you know opposite ÷ hypotenuse.

## Learning goal

Find an angle with inverse sine.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 3 5
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run with sides 3 and 5.
2. Try opposite 5 and hypotenuse 5.
3. Double both inputs and compare the angle.
