# Lab: The Sine Wave

## Main idea

As an angle turns around a circle, its y-coordinate rises and falls. Plotting that height makes a repeating sine wave.

## Learning goal

See sine values change through one turn.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 30
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run with a 30° step.
2. Try a smaller 15° step.
3. Find where the values are highest and lowest.

## Think about it

- What changed when you changed an input?
- What stayed the same?
- Explain the main idea in one simple sentence.

## Success check

You are ready to move on when you can predict one output before running the simulation and explain whether your prediction was correct.
