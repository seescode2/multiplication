# Lab: Triangle Area with Sine

## Main idea

Two sides and the angle between them determine a triangle’s area: area = ½ab sin(C).

## Learning goal

Find triangle area using sine.

## Run the simulation

You need [Node.js](https://nodejs.org/) installed. From this folder, run:

```bash
node app.js 6 8 30
```

The values after `app.js` are inputs. Change them, run the command again, and compare the output. No packages or setup are needed.

## Directions

1. Run with sides 6 and 8 and angle 30°.
2. Try 90° for the angle.
3. Compare 30° and 150°.
