# Trigonometry Simulation Labs

Thirty small, beginner-friendly trigonometry labs. Each concept is now a dependency-free visual web app with responsive controls, a live diagram, and calculated results.

## How to use the labs

1. Start with Lab 1 or choose a concept below.
2. Open the linked lesson, then launch its `index.html` simulation in a modern browser.
3. Move the sliders and watch the diagram and calculated values update instantly.
4. Predict, experiment, and explain what happened. No installation or terminal is required.
