# Trigonometry Simulation Labs

Thirty small, beginner-friendly trigonometry labs. Each folder contains a `lab.md` lesson and a dependency-free Node.js `app.js` simulation.

## How to use the labs

1. Start with Lab 1 or choose a concept below.
2. Open its `lab.md` and read the main idea and learning goal.
3. Follow the directions and run the JavaScript with Node.js.
4. Predict, change the inputs, run again, and explain what happened.
